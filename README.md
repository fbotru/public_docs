# Документация AFL-Ассистента

[![Deploy documentation to GitHub Pages](https://github.com/fbotru/public_docs/actions/workflows/deploy.yml/badge.svg)](https://github.com/fbotru/public_docs/actions/workflows/deploy.yml)

Документация собрана с помощью MkDocs Material и публикуется через GitHub Pages.

## Локальный запуск

```bash
uv sync --locked
uv run mkdocs serve
```

После запуска сайт доступен по адресу <http://127.0.0.1:8000>.
