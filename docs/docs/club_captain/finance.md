# Долги и финансовый отчёт

Этот раздел работает только когда клуб включил финансовый учёт. При выключенных оплатах бот продолжает вести тренировки и посещаемость, но не создаёт долги и не формирует финансовый отчёт. Ранее сохранённые финансовые данные остаются в системе и снова становятся доступны после включения оплат.

## Активные долги

Откройте **Клуб → Управление клубом → Активные долги**. Список можно фильтровать:

- по статусу: все, ожидают, на проверке или просроченные;
- по виду события: тренировки или игры.

В строке игрока показана итоговая сумма. Откройте долг, чтобы увидеть событие, основную сумму, наценку, срок и историю.

## Обработать долг

Для активного долга доступны действия:

- отметить оплату наличными;
- списать долг с подходящего абонемента;
- отменить долг.

Каждое действие требует подтверждения. Списать долг с абонемента можно только при наличии подходящего абонемента этого клуба. После обработки игрок получает уведомление.

Не подтверждайте наличную оплату до фактического получения денег. Отмену используйте для ошибочных долгов, а не для предоставления скидки: отменённый долг перестаёт учитываться как активный.

## Финансовый отчёт

1. Откройте **Клуб → Управление клубом → Финансовый отчёт**.
2. В календаре выберите дату начала периода.
3. Выберите дату окончания.
4. Дождитесь формирования документа.

Бот отправит файл отчёта и укажет количество строк. Отчёт ограничен вашим клубом, даже если в системе работают другие клубы.

Если файл не сформировался, повторите попытку позже или выберите меньший период. Для оперативной проверки конкретного наличного платежа используйте карточку долга, а не отчёт.
