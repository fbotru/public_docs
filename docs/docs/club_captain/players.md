# Игроки и абонементы

Список игроков доступен всегда. Управление абонементами относится к опциональному финансовому учёту и становится доступно после включения оплат клуба.

## Найти игрока

Откройте **Клуб → Управление клубом → Пользователи**. Можно открыть общий список или найти игрока по имени. Раздел показывает только активных пользователей вашего клуба.

В карточке игрока доступны основные сведения и, на Standard, кнопка **Управление абонементами**.

## Начислить события

1. Откройте карточку игрока.
2. Нажмите **Управление абонементами → Начислить**.
3. Укажите количество событий.
4. Выберите вид абонемента: тренировки или игры.
5. Подтвердите действие.

Если подходящего абонемента ещё нет, бот создаст запись для выбранного типа. Игрок получит уведомление об изменении остатка.

## Списать события

В том же разделе нажмите **Списать**, выберите количество и вид абонемента. Используйте ручное списание для исправления учёта, а не вместо штатного завершения тренировки.

Если списание уводит остаток в минус, у игрока возникает задолженность по событиям. При следующей покупке этого вида абонемента бот сначала предложит её погасить.

## Настроить каталог абонементов

Откройте **Клуб → Управление клубом → Настройки абонементов** и выберите **Тренировки** или **Игры**.

Для каждого варианта задаются:

- цена;
- количество событий;
- срок действия в днях;
- включён или выключен тариф.

Можно добавить новый тариф либо изменить существующий. Игроки видят только включённые варианты. Если клуб использует общие настройки, первое изменение создаёт собственный клубный каталог. Кнопка **Сбросить к общим настройкам** удаляет клубные отличия для выбранного типа.

## Наценка за задолженность

В главном экране настроек абонементов выберите **Наценка за задолженность**. Она применяется к неоплаченным наличным и к погашению минусового остатка абонемента. При расчёте долга по событиям наценка умножается на количество событий в минусе.

Можно задать клубное значение или вернуться к общей наценке.
