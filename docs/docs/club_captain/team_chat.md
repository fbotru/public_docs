# Подготовка командного чата

Добавьте AFL-Ассистента в Telegram-чат команды и назначьте администратором. Это нужно, чтобы бот мог работать с чатом и получать его актуальное название.

## Добавить бота

Названия пунктов могут немного отличаться в разных версиях Telegram, но порядок действий остаётся тем же:

1. Откройте командный чат.
2. Нажмите на название чата, чтобы открыть его карточку.
3. Перейдите в управление участниками. Обычно этот пункт называется **Участники**, **Добавить участников** или находится в меню **Ещё**.
4. Нажмите **Добавить участника**.
5. Найдите AFL-Ассистента по его Telegram-имени.
6. Выберите бота и подтвердите добавление.

Перед подтверждением проверьте имя аккаунта: добавлять нужно именно рабочего бота AFL-Ассистента, которым пользуются игроки клуба.

## Выдать права администратора

1. Снова откройте карточку командного чата.
2. Перейдите в **Управление → Администраторы**.
3. Нажмите **Добавить администратора** и выберите AFL-Ассистента.
4. Разрешите боту отправлять сообщения и выполнять действия, необходимые для работы с чатом.
5. Сохраните изменения.

Не выдавайте лишние права, если Telegram позволяет настроить их отдельно. Для обычной работы боту не требуется передавать владение чатом.

## Проверить подключение

Откройте **Клуб → Управление клубом → Команды** и выберите нужную команду. Если у неё уже указан Telegram-чат, нажмите **Обновить имя чата**.

Успешное обновление означает, что бот видит чат. Если имя получить не удалось, проверьте:

- бот действительно состоит в нужном чате;
- у команды указан правильный Telegram ID чата;
- бот не заблокирован и имеет необходимые права;
- вы открыли команду своего клуба.

Telegram ID чата и привязку команды меняет администрация сервиса. Если чат добавлен правильно, но в карточке команды он отсутствует или указан неверно, передайте администрации название клуба, команды и чата.
