# Команды, рейтинг и SMM

## Команды клуба

Откройте **Клуб → Управление клубом → Команды**. Капитан видит только команды своего клуба и может открыть карточку команды.

Если у команды указан Telegram-чат и бот добавлен в него, доступно обновление названия чата. При ошибке проверьте, что чат привязан к команде, бот добавлен и имеет нужные права.

Создание команд и изменение системных полей выполняет администрация сервиса; клубный раздел капитана предназначен для безопасного просмотра и работы со своими командами.

## Обновить клубный рейтинг

В **Управлении клубом** нажмите **Обновить клубный рейтинг**. Бот покажет количество найденных матчей текущего сезона и попросит подтверждение.

После запуска расчёт идёт в фоне. Не запускайте его повторно: для одного клуба одновременно выполняется только одно обновление. По завершении бот отправит отчёт. Если подходящих матчей с сохранённым KPI нет, обновление не начнётся.

Сам рейтинг игроки открывают кнопкой **Клубный рейтинг** в главном меню.

## SMM

Раздел **Клуб → Управление клубом → SMM** содержит оформление клубных изображений:

- **Стили** — просмотр доступных оформлений и выбор текущего;
- **Посмотреть стили** — подборки с визуальными вариантами;
- **Примеры** — образцы изображений, которые умеет создавать бот.

Standard включает базовые возможности SMM и доступные этому тарифу стили. Если конкретный стиль требует более высокого тарифа, выбрать его не получится.

## Подписка клуба

Откройте **Клуб → Подписка**, чтобы проверить текущий тариф. На Basic капитан может отправить заявку на подключение Standard; повторная заявка не создаётся, пока предыдущая ожидает обработки.

После подключения Standard появляются тренировки и клубный рейтинг. Оплаты, абонементы и финансовый отчёт становятся доступны после отдельного включения финансового учёта. Если нужная кнопка пропала, проверьте текущий тариф, настройку оплат и свой статус действующего капитана.
