# Абонементы

## Виды абонементов

В Standard есть два независимых вида:

- **Тренировки** — используются при завершении клубной тренировки;
- **Игры** — используются, когда вы попали в состав на матч.

Каждый вариант имеет цену, количество событий и срок действия в днях. Клуб может предлагать несколько вариантов и отключать временно недоступные.

## Купить абонемент

1. Откройте **Меню → Профиль → Абонементы**.
2. Выберите **Тренировки** или **Игры**.
3. Выберите количество событий из предложенных вариантов.
4. Проверьте сумму и нажмите **Оплатить картой**.
5. Выполните инструкцию клуба и отправьте чек по запросу бота.

Кнопка оплаты действует ограниченное время. Если она устарела, начните покупку заново через профиль.

## Остаток и срок действия

Информация об абонементах отображается в профиле. После завершённой тренировки или учтённой игры бот сообщает, сколько событий осталось.

Если событий не хватает, участие может образовать задолженность. При следующей покупке абонемента этого типа бот сначала предложит оплатить долг. К сумме может добавляться установленная клубом наценка за каждое событие в минусе.

## История и отчёт

В профиле доступны:

- **История абонементов** — изменения и операции по вашим абонементам;
- **Отчёт абонементов** — выгрузка операций;
- **Статистика** — учтённые игры и другие личные показатели.

У игрока с безлимитным абонементом кнопка покупки может не показываться: посещения учитываются без уменьшения остатка.
